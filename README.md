# Real Time Word Counter (VS Code Extension)

A simple VS Code extension for real-time typing practice: live word count, adjustable word limit, and a countdown timer right in the status bar.

## Features

- Live word count in the status bar: `Words: 143 / 250` with over-limit warning
- Adjustable word limit: click the status bar, or `Ctrl+Alt+↑/↓`
- Countdown timer with `Ctrl+Alt+→/←` adjustments
- Commands: `Ctrl+Shift+P` → "Exam Counter: ..."

## Install from source

Copy this folder to `%USERPROFILE%\.vscode\extensions\`, reload VS Code.

## Usage

1. Open any text file
2. Click the status bar counter to adjust words/time
3. `Ctrl+Shift+P` → "Exam Counter: Start Timer"
